# Amazon India Dashboard
A management dashboard built in Excel for Amazon India sales data
(10,000 orders, Jan 2024 – Aug 2026).

Sections: Sales & Profit, Category & Product, Order Status & Revenue Loss,
Payment, Fulfillment & State performance.

Files:
- Amazon_India_Dashboard.xlsx – the dashboard
- Amazon_Sales_Data_India.xlsx – the original data
